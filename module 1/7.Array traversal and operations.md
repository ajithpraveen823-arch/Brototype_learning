# 🟨 Understand Array Traversal and Operations 🔄📦

> 🚀 **Array traversal** means going through the elements of an array one by one.
> **Array operations** allow you to add, remove, and transform elements easily.

---

# 🌟 1. Iterating Through Arrays Using Loops

**Iteration** means accessing each array element one by one.

Suppose we have:

```javascript
let fruits = ["Apple", "Mango", "Banana", "Orange"];
```

---

## 🔹 Using `for` Loop

```javascript
let fruits = ["Apple", "Mango", "Banana", "Orange"];

for (let i = 0; i < fruits.length; i++) {
    console.log(fruits[i]);
}
```

### 🖥️ Output

```text
Apple
Mango
Banana
Orange
```

### 🧠 How it works

```text
Index
  ↓
  0       1        2         3
┌──────┬────────┬────────┬────────┐
│Apple │ Mango  │ Banana │ Orange │
└──────┴────────┴────────┴────────┘
   ↑
   i
```

---

# 🔄 2. Using `for...of`

`for...of` directly gives you the **values** of an array.

```javascript
let fruits = ["Apple", "Mango", "Banana"];

for (let fruit of fruits) {
    console.log(fruit);
}
```

### 🖥️ Output

```text
Apple
Mango
Banana
```

### ⭐ Easy to remember

```text
for...of → VALUES
```

---

# 🔢 3. Using `forEach()`

`forEach()` executes a function for every element in an array.

```javascript
let fruits = ["Apple", "Mango", "Banana"];

fruits.forEach(function(fruit) {
    console.log(fruit);
});
```

You can also use an arrow function:

```javascript
fruits.forEach(fruit => {
    console.log(fruit);
});
```

### 🖥️ Output

```text
Apple
Mango
Banana
```

---

# 📥📤 4. Input / Output Using Arrays

Arrays are commonly used to **store input values** and later **display or process those values**.

### 📥 Taking input with `prompt()`

In a browser:

```javascript
let fruits = [];

let fruit1 = prompt("Enter first fruit:");
let fruit2 = prompt("Enter second fruit:");
let fruit3 = prompt("Enter third fruit:");

fruits.push(fruit1);
fruits.push(fruit2);
fruits.push(fruit3);

console.log(fruits);
```

If the user enters:

```text
Apple
Mango
Banana
```

The array becomes:

```javascript
["Apple", "Mango", "Banana"]
```

### 📤 Displaying the array

```javascript
console.log(fruits);
```

Or:

```javascript
fruits.forEach(fruit => {
    console.log(fruit);
});
```

# ➕ 5. `push()` – Add to the End

`push()` adds one or more elements to the **end** of an array.

```javascript
let fruits = ["Apple", "Mango"];

fruits.push("Banana");

console.log(fruits);
```

### 🖥️ Output

```text
["Apple", "Mango", "Banana"]
```

### 📌 Multiple elements

```javascript
fruits.push("Orange", "Grapes");
```

Result:

```text
["Apple", "Mango", "Banana", "Orange", "Grapes"]
```

### 🧠 Remember

```text
push()
  ↓
ADD → END
```

---

# ➖ 6. `pop()` – Remove from the End

`pop()` removes the **last element**.

```javascript
let fruits = ["Apple", "Mango", "Banana"];

fruits.pop();

console.log(fruits);
```

### 🖥️ Output

```text
["Apple", "Mango"]
```

`pop()` also **returns the removed element**:

```javascript
let fruits = ["Apple", "Mango", "Banana"];

let removed = fruits.pop();

console.log(removed);
```

Output:

```text
Banana
```

### 🧠 Remember

```text
pop()
  ↓
REMOVE ← END
```

---

# ⬅️ 7. `shift()` – Remove from the Beginning

`shift()` removes the **first element**.

```javascript
let fruits = ["Apple", "Mango", "Banana"];

fruits.shift();

console.log(fruits);
```

### 🖥️ Output

```text
["Mango", "Banana"]
```

It also returns the removed element:

```javascript
let removed = fruits.shift();

console.log(removed);
```

### 🧠 Remember

```text
shift()
  ↓
REMOVE ← START
```

---

# ➡️ 8. `unshift()` – Add to the Beginning

`unshift()` adds one or more elements to the **beginning**.

```javascript
let fruits = ["Mango", "Banana"];

fruits.unshift("Apple");

console.log(fruits);
```

### 🖥️ Output

```text
["Apple", "Mango", "Banana"]
```

### 🧠 Remember

```text
unshift()
    ↓
ADD → START
```

---

# 📊 9. `push`, `pop`, `shift`, `unshift`

This is very important to remember:

```text
                 ARRAY
        ┌─────────────────────┐
 START  │ Apple │ Mango │ ... │ END
        └─────────────────────┘
          ↑                 ↑
       shift()            pop()
       REMOVE             REMOVE

       unshift()          push()
       ADD                ADD
```

| Method      | Action   | Location  |
| ----------- | -------- | --------- |
| `push()`    | ➕ Add    | End       |
| `pop()`     | ➖ Remove | End       |
| `shift()`   | ➖ Remove | Beginning |
| `unshift()` | ➕ Add    | Beginning |

### 🎯 Easy Trick

```text
push    → ADD    → END
pop     → REMOVE → END

unshift → ADD    → START
shift   → REMOVE → START
```

# 🗺️ 10. `map()` – Transform Every Element

`map()` creates a **new array** by applying a function to every element.

### Example

```javascript
let numbers = [1, 2, 3, 4, 5];

let doubled = numbers.map(number => number * 2);

console.log(doubled);
```

### 🖥️ Output

```text
[2, 4, 6, 8, 10]
```

### 🧠 Think of it like:

```text
Original
   ↓
[1, 2, 3, 4, 5]
   ↓
  map()
   ↓
× 2
   ↓
[2, 4, 6, 8, 10]
```

### ⭐ Important

`map()` does **not normally change the original array**.

```javascript
let numbers = [1, 2, 3];

let result = numbers.map(n => n * 2);

console.log(numbers);
console.log(result);
```

Output:

```text
[1, 2, 3]
[2, 4, 6]
```

---

# 🔍 11. `filter()` – Select Elements

`filter()` creates a new array containing only the elements that satisfy a condition.

### Example

```javascript
let numbers = [1, 2, 3, 4, 5, 6];

let evenNumbers = numbers.filter(number => number % 2 === 0);

console.log(evenNumbers);
```

### 🖥️ Output

```text
[2, 4, 6]
```

### 🧠 Think of it like a filter:

```text
[1, 2, 3, 4, 5, 6]
       ↓
     filter
       ↓
Keep only EVEN numbers
       ↓
[2, 4, 6]
```

---

# ➕ 12. `reduce()` – Reduce to One Value

`reduce()` processes all elements and produces **one final value**.

It is commonly used for:

* ➕ Sum
* ✖️ Product
* 📊 Calculations
* 🧮 Totals

### Example – Sum

```javascript
let numbers = [10, 20, 30, 40];

let total = numbers.reduce((sum, number) => {
    return sum + number;
}, 0);

console.log(total);
```

### 🖥️ Output

```text
100
```

### 🧠 How it works

```text
10 + 20 = 30
30 + 30 = 60
60 + 40 = 100
```

Final result:

```text
100
```

---

# 🧮 `reduce()` Visual

```text
[10, 20, 30, 40]
       ↓
    reduce()
       ↓
  10 + 20
       ↓
     30
       ↓
  30 + 30
       ↓
     60
       ↓
  60 + 40
       ↓
    100
```

---

# ⚔️ `map()` vs `filter()` vs `reduce()`

| Method     | Purpose            | Result            |
| ---------- | ------------------ | ----------------- |
| `map()`    | Transform elements | New array         |
| `filter()` | Select elements    | New array         |
| `reduce()` | Combine elements   | Usually one value |

### 🔥 Easy Formula

```text
map
 ↓
CHANGE

filter
 ↓
SELECT

reduce
 ↓
COMBINE
```

# 🌍 Real-World Example

Imagine an online shopping cart:

```javascript
let prices = [500, 1000, 1500, 2000];
```

### 💰 Double each price

```javascript
let doubled = prices.map(price => price * 2);

console.log(doubled);
```

Output:

```text
[1000, 2000, 3000, 4000]
```

### 🔍 Find prices above ₹1000

```javascript
let expensive = prices.filter(price => price > 1000);

console.log(expensive);
```

Output:

```text
[1500, 2000]
```

### 💵 Calculate total

```javascript
let total = prices.reduce((sum, price) => sum + price, 0);

console.log(total);
```

Output:

```text
5000
```
