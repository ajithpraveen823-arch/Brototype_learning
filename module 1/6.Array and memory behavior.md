# 🟨 Understand Arrays and Memory Behavior 📦🧠

> 🚀 **Arrays** are one of the most important data structures in JavaScript. They allow you to store **multiple values inside a single variable**.

---

# 🌟 1. What is an Array?

An **array** is a collection of multiple values stored in a single variable.

Instead of:

```javascript
let fruit1 = "Apple";
let fruit2 = "Mango";
let fruit3 = "Banana";
```

We can use an array:

```javascript
let fruits = ["Apple", "Mango", "Banana"];
```

### 🧠 Think of an array like a box

```text
📦 fruits

┌─────────┬─────────┬─────────┐
│  Apple  │  Mango  │  Banana │
└─────────┴─────────┴─────────┘
     0         1         2
   Index     Index     Index
```

> ⭐ **Important:** JavaScript arrays use **zero-based indexing**, meaning the first element has index `0`.

---

# 🛠️ 2. Declaring and Initializing Arrays

There are several ways to create an array.

## 🔹 Method 1: Array Literal ⭐ Recommended

The most common method is using square brackets `[]`.

```javascript
let fruits = ["Apple", "Mango", "Banana"];
```

You can also create an empty array:

```javascript
let fruits = [];
```

Then add elements:

```javascript
fruits.push("Apple");
fruits.push("Mango");

console.log(fruits);
```

Output:

```text
["Apple", "Mango"]
```

---

## 🔹 Method 2: `new Array()`

You can also use the `Array` constructor.

```javascript
let fruits = new Array("Apple", "Mango", "Banana");

console.log(fruits);
```

Output:

```text
["Apple", "Mango", "Banana"]
```

### 💡 Recommendation

Prefer:

```javascript
let fruits = ["Apple", "Mango", "Banana"];
```

instead of:

```javascript
let fruits = new Array("Apple", "Mango", "Banana");
```

The array literal is simpler and easier to read.

---

# 📊 3. Arrays Can Store Different Data Types

JavaScript arrays can contain different types of values.

```javascript
let data = [
    "Ajith",
    21,
    true,
    null
];

console.log(data);
```

Output:

```text
["Ajith", 21, true, null]
```

You can even have objects and arrays inside an array:

```javascript
let student = [
    "Ajith",
    21,
    {
        course: "MERN"
    }
];
```

> ⚠️ In real projects, it's usually better to keep an array's elements logically related.

---

# 🔢 4. Indexing and Accessing Elements

Every element in an array has an **index**.

### Example

```javascript
let fruits = ["Apple", "Mango", "Banana", "Orange"];
```

The indexes are:

```text
┌─────────┬─────────┬─────────┬─────────┐
│  Apple  │  Mango  │  Banana │ Orange  │
└─────────┴─────────┴─────────┴─────────┘
     0         1         2         3
```

### Access an element

```javascript
console.log(fruits[0]);
```

Output:

```text
Apple
```

```javascript
console.log(fruits[2]);
```

Output:

```text
Banana
```

---

# ✏️ 5. Changing Array Elements

Arrays are **mutable**, meaning their elements can be changed.

```javascript
let fruits = ["Apple", "Mango", "Banana"];

fruits[1] = "Orange";

console.log(fruits);
```

Output:

```text
["Apple", "Orange", "Banana"]
```

### 🧠 Remember

```text
fruits[1]
   ↓
"Mango"
   ↓
change it
   ↓
"Orange"
```

---

# 📏 6. Array Length

The `.length` property tells you how many elements are in an array.

```javascript
let fruits = ["Apple", "Mango", "Banana"];

console.log(fruits.length);
```

Output:

```text
3
```

### 🔥 Important

For an array with 3 elements:

```text
Elements → 3
Indexes  → 0, 1, 2
```

So:

```javascript
fruits.length
```

is `3`, but the last index is:

```javascript
fruits.length - 1
```

which is `2`.

# 🧠 7. Primitive vs Reference Behavior

This is a **very important JavaScript concept**.

JavaScript values can broadly be understood as:

```text
JavaScript Values
       │
 ┌─────┴─────┐
 │           │
Primitive   Objects
 │           │
 │           └── Arrays
 │               Objects
 │               Functions
 │
 └── string
     number
     boolean
     null
     undefined
     bigint
     symbol
```

Arrays are **objects**, so they behave differently from primitive values.

---

# 🔹 8. Primitive Behavior

Primitive values are copied as **values**.

### Example

```javascript
let a = 10;
let b = a;

b = 20;

console.log(a);
console.log(b);
```

Output:

```text
10
20
```

### 🧠 What happened?

```text
a = 10

a ───→ 10

b = a

a ───→ 10
b ───→ 10

b = 20

a ───→ 10
b ───→ 20
```

Changing `b` does not change `a`.

---

# 🔗 9. Reference Behavior with Arrays

Arrays are objects, so assigning an array to another variable copies the **reference to the same array object**.

### Example

```javascript
let fruits1 = ["Apple", "Mango"];

let fruits2 = fruits1;

fruits2.push("Banana");

console.log(fruits1);
console.log(fruits2);
```

Output:

```text
["Apple", "Mango", "Banana"]

["Apple", "Mango", "Banana"]
```

😮 Why did `fruits1` also change?

Because both variables refer to the **same array object**.

### 🧠 Memory idea

```text
fruits1 ─────┐
             ↓
        ┌───────────────┐
        │ Apple         │
        │ Mango         │
        │ Banana        │
        └───────────────┘
             ↑
fruits2 ─────┘
```

So:

```javascript
fruits1 === fruits2
```

gives:

```text
true
```

---

# ⚡ 10. Creating a Separate Array

If you want a new array with the same elements, you can use the spread operator `...`.

```javascript
let fruits1 = ["Apple", "Mango"];

let fruits2 = [...fruits1];

fruits2.push("Banana");

console.log(fruits1);
console.log(fruits2);
```

Output:

```text
["Apple", "Mango"]

["Apple", "Mango", "Banana"]
```

### 🧠 Memory idea

```text
fruits1 ───→ 📦 ["Apple", "Mango"]

fruits2 ───→ 📦 ["Apple", "Mango", "Banana"]
```

Now they are separate arrays.

```javascript
console.log(fruits1 === fruits2);
```

Output:

```text
false
```

---

# ⚠️ 11. `const` with Arrays

A common beginner question:

> "If an array is declared using `const`, can I change its elements?"

### ✅ Yes!

```javascript
const fruits = ["Apple", "Mango"];

fruits.push("Banana");

console.log(fruits);
```

Output:

```text
["Apple", "Mango", "Banana"]
```

You can modify the array.

### ❌ But you cannot reassign the variable

```javascript
const fruits = ["Apple", "Mango"];

fruits = ["Banana", "Orange"];
```

This causes an error because `const` prevents reassignment of the variable.

### 🧠 Remember

```text
const array
     │
     ├── Modify contents ✅
     │
     └── Reassign variable ❌
```

# 🔥 12. Quick Comparison

| Feature              | Primitive      | Array              |
| -------------------- | -------------- | ------------------ |
| Example              | `let x = 10`   | `let x = [10, 20]` |
| Category             | Primitive      | Object             |
| Assignment           | Value copied   | Reference copied   |
| Mutable              | No             | Yes                |
| Can change contents? | ❌              | ✅                  |
| Example              | Number, String | Array              |
