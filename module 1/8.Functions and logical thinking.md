# 🟨 Understand Functions and Logical Thinking 🧠⚙️

> 🚀 **Functions** are reusable blocks of code designed to perform a specific task. They help you organize your program, avoid repeating code, and build logical thinking.

---

# 🌟 1. What is a Function?

A function is a block of code that runs **when you call it**.

### 💡 Simple Example

```javascript
function greet() {
    console.log("Hello, Ajith!");
}

greet();
```

### 🖥️ Output

```text
Hello, Ajith!
```

### 🧠 Flow

```text
        Function
           ↓
     ┌─────────────┐
     │   greet()   │
     │             │
     │ Hello!      │
     └─────────────┘
           ↓
       Call it
           ↓
        Output
```

---

# 🔹 2. Function Declaration

A **function declaration** defines a function using the `function` keyword.

### 📌 Syntax

```javascript
function functionName() {
    // code
}
```

### 💻 Example

```javascript
function greet() {
    console.log("Hello!");
}

greet();
```

### 🖥️ Output

```text
Hello!
```

---

## ⭐ Function Declaration with Parameters

```javascript
function greet(name) {
    console.log("Hello " + name);
}

greet("Ajith");
greet("Rahul");
```

### 🖥️ Output

```text
Hello Ajith
Hello Rahul
```

Here:

```text
name → Parameter
"Ajith" → Argument
```

---

# 🔵 3. Function Expression

A **function expression** stores a function inside a variable.

### 📌 Syntax

```javascript
const functionName = function() {
    // code
};
```

### 💻 Example

```javascript
const greet = function() {
    console.log("Hello!");
};

greet();
```

### 🖥️ Output

```text
Hello!
```

---

## ⚔️ Declaration vs Expression

### Function Declaration

```javascript
function add(a, b) {
    return a + b;
}
```

### Function Expression

```javascript
const add = function(a, b) {
    return a + b;
};
```

Both can perform the same task.

### 🧠 Main Difference

| Feature                          | Function Declaration | Function Expression        |
| -------------------------------- | -------------------- | -------------------------- |
| Uses `function`                  | ✅                    | ✅                          |
| Stored in variable               | ❌                    | ✅                          |
| Can be called before declaration | Generally ✅          | ❌                          |
| Common syntax                    | `function add(){}`   | `const add = function(){}` |

# ⚡ 4. Arrow Functions

Arrow functions provide a **shorter syntax** for writing functions.

They use the `=>` symbol.

### 📌 Normal Function

```javascript
function add(a, b) {
    return a + b;
}
```

### ⚡ Arrow Function

```javascript
const add = (a, b) => {
    return a + b;
};
```

### 🖥️ Example

```javascript
const result = add(10, 20);

console.log(result);
```

Output:

```text
30
```

---

# ✨ 5. Short Arrow Function

If the function contains only one expression, you can make it even shorter.

```javascript
const add = (a, b) => a + b;

console.log(add(10, 20));
```

Output:

```text
30
```

### More examples

```javascript
const square = n => n * n;

console.log(square(5));
```

Output:

```text
25
```

```javascript
const greet = name => `Hello ${name}`;

console.log(greet("Ajith"));
```

Output:

```text
Hello Ajith
```

# 📥 6. Parameters and Arguments

These two terms are important.

### Parameter

A **parameter** is the variable written in the function definition.

```javascript
function greet(name) {
    console.log("Hello " + name);
}
```

Here:

```text
name → Parameter
```

### Argument

An **argument** is the actual value passed when calling the function.

```javascript
greet("Ajith");
```

Here:

```text
"Ajith" → Argument
```

### 🧠 Easy Formula

```text
Function definition
       ↓
   parameter
       ↓
function greet(name)

Function call
       ↓
    argument
       ↓
greet("Ajith")
```

# 🔄 7. Multiple Parameters

A function can accept multiple parameters.

```javascript
function add(a, b) {
    console.log(a + b);
}

add(10, 20);
```

Output:

```text
30
```

Here:

```text
a = 10
b = 20
```

# 🎁 8. Return Values

The `return` statement sends a value **back from the function**.

### Example

```javascript
function add(a, b) {
    return a + b;
}

let result = add(10, 20);

console.log(result);
```

### 🖥️ Output

```text
30
```

### 🧠 Flow

```text
add(10, 20)
     ↓
  Function
     ↓
  10 + 20
     ↓
   return
     ↓
    30
     ↓
 result
```

---

# ⚠️ `console.log()` vs `return`

These are **not the same**.

### `console.log()`

Displays something in the console.

```javascript
function add(a, b) {
    console.log(a + b);
}
```

### `return`

Sends the value back so you can use it elsewhere.

```javascript
function add(a, b) {
    return a + b;
}

let result = add(10, 20);

console.log(result);
```

### ⭐ Remember

```text
console.log()
     ↓
DISPLAY 📺

return
     ↓
SEND BACK 📤
```

# ♻️ 9. Breaking Logic into Reusable Functions

One of the biggest advantages of functions is **reusability**.

### ❌ Without functions

```javascript
let a = 10;
let b = 20;

console.log(a + b);

let x = 30;
let y = 40;

console.log(x + y);
```

We are repeating logic.

### ✅ With a function

```javascript
function add(a, b) {
    return a + b;
}

console.log(add(10, 20));
console.log(add(30, 40));
console.log(add(50, 60));
```

Output:

```text
30
70
110
```

### 🧠 One function → Many uses

```text
          add()
            │
     ┌──────┼──────┐
     ↓      ↓      ↓
  10 + 20 30 + 40 50 + 60
     ↓      ↓      ↓
    30     70     110
```

# 🧩 10. Real-World Example

Imagine an e-commerce website.

Instead of writing discount logic everywhere:

```javascript
function calculateDiscount(price, discount) {
    return price - (price * discount / 100);
}

console.log(calculateDiscount(1000, 10));
console.log(calculateDiscount(2000, 20));
```

Output:

```text
900
1600
```

The same function can be reused for hundreds of products.

# 🏗️ 11. Breaking a Large Problem into Functions

Suppose you are creating a student result system.

Instead of putting everything into one huge block:

```text
Student Program
      │
      ├── Get Marks
      │
      ├── Calculate Total
      │
      ├── Calculate Average
      │
      ├── Find Grade
      │
      └── Display Result
```

You can create separate functions:

```javascript
function calculateTotal(marks) {
    return marks.reduce((total, mark) => total + mark, 0);
}

function calculateAverage(total, subjects) {
    return total / subjects;
}

function getGrade(average) {
    if (average >= 90) return "A+";
    if (average >= 80) return "A";
    if (average >= 70) return "B";
    if (average >= 60) return "C";
    return "F";
}
```

Then:

```javascript
let marks = [85, 90, 78, 92, 88];

let total = calculateTotal(marks);
let average = calculateAverage(total, marks.length);
let grade = getGrade(average);

console.log("Total:", total);
console.log("Average:", average);
console.log("Grade:", grade);
```

This makes your code **cleaner, easier to test, and easier to maintain**.
