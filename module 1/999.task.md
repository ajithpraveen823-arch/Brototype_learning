# 🌟 1. Build Small Logic-Based Programs

Start with simple programs that require you to **think about the logic before writing code**.

### 🟢 Program 1 – Check Even or Odd

### 🧠 Logic

```text
1. Get a number
2. Divide it by 2
3. If remainder is 0 → Even
4. Otherwise → Odd
```

### 💻 Code

```javascript
let number = 15;

if (number % 2 === 0) {
    console.log("Even");
} else {
    console.log("Odd");
}
```

### 🖥️ Output

```text
Odd
```

# 🔄 Program 3 – Reverse a Number

### 🧠 Example

```text
Input  → 12345
Output → 54321
```

### 💻 Code

```javascript
let number = 12345;
let reversed = 0;

while (number > 0) {
    let digit = number % 10;
    reversed = reversed * 10 + digit;
    number = Math.floor(number / 10);
}

console.log(reversed);
```

### 🖥️ Output

```text
54321
```

# ♻️ 3. Use Functions to Organize Logic

Instead of putting everything into one large program, divide the logic into **small reusable functions**.

### ❌ Hard to manage

```javascript
let numbers = [10, 20, 30, 40];

let sum = 0;

for (let number of numbers) {
    sum += number;
}

console.log(sum);

let largest = numbers[0];

for (let number of numbers) {
    if (number > largest) {
        largest = number;
    }
}

console.log(largest);
```

It works, but becomes difficult to manage as the program grows.

---

## ✅ Better Approach

```javascript
function calculateSum(numbers) {

    let sum = 0;

    for (let number of numbers) {
        sum += number;
    }

    return sum;
}

function findLargest(numbers) {

    let largest = numbers[0];

    for (let number of numbers) {

        if (number > largest) {
            largest = number;
        }
    }

    return largest;
}

let numbers = [10, 20, 30, 40];

console.log("Sum:", calculateSum(numbers));
console.log("Largest:", findLargest(numbers));
```

### 🖥️ Output

```text
Sum: 100
Largest: 40
```

### 🧠 Structure

```text
📦 Program
   │
   ├── calculateSum()
   │
   ├── findLargest()
   │
   └── Main Code
```

This is much easier to understand and reuse.

# 🧹 4. Practice Writing Readable Code

Good code is not only code that works.

It should also be:

* 👀 Easy to read
* 🧠 Easy to understand
* ♻️ Easy to reuse
* 🛠️ Easy to modify
* 🐛 Easy to debug

---

## ❌ Avoid confusing code

```javascript
let x=[10,20,30,40];let y=0;for(let z of x){y+=z;}console.log(y);
```

This may work, but it is difficult to read.

---

## ✅ Write structured code

```javascript
let numbers = [10, 20, 30, 40];

let sum = 0;

for (let number of numbers) {
    sum += number;
}

console.log("Total:", sum);
```

Much better! ✨

# 📝 5. Use Meaningful Variable Names

### ❌ Poor naming

```javascript
let x = 500;
let y = 10;

let z = x - (x * y / 100);
```

### ✅ Better naming

```javascript
let price = 500;
let discount = 10;

let finalPrice = price - (price * discount / 100);
```

### 🧠 Rule

> **Variable names should explain what the data represents.**

Good:

```javascript
let studentName;
let totalMarks;
let productPrice;
let isLoggedIn;
```

Avoid unnecessary names like:

```javascript
let x;
let y;
let a;
let temp1;
```

# 🐛 6. Identify and Fix Logical Mistakes

A **logical error** happens when the program runs but produces the **wrong result**.

---

## ❌ Example

Suppose we want to find even numbers:

```javascript
let number = 10;

if (number % 2 === 1) {
    console.log("Even");
} else {
    console.log("Odd");
}
```

The program runs, but:

```text
Expected → Even
Actual   → Odd
```

### 🐛 Find the mistake

We used:

```javascript
number % 2 === 1
```

But an even number has remainder `0`.

### ✅ Fixed

```javascript
let number = 10;

if (number % 2 === 0) {
    console.log("Even");
} else {
    console.log("Odd");
}
```

Output:

```text
Even
```

# 🔍 7. Debugging Step-by-Step

When your program gives the wrong answer, don't immediately rewrite everything.

Follow this process:

```text
🐛 Wrong Output
      ↓
🤔 What did I expect?
      ↓
🔍 Check the input
      ↓
🔍 Check the condition
      ↓
🔍 Check the loop
      ↓
🔍 Check variable values
      ↓
🛠️ Fix the mistake
      ↓
✅ Test again
```

# 🧪 8. Use `console.log()` for Debugging

Suppose this code isn't working:

```javascript
let numbers = [10, 20, 30];

let sum = 0;

for (let number of numbers) {
    sum += number;
}

console.log(sum);
```

You can inspect values while the program runs:

```javascript
let numbers = [10, 20, 30];

let sum = 0;

for (let number of numbers) {

    console.log("Current number:", number);

    sum += number;

    console.log("Current sum:", sum);
}

console.log("Final sum:", sum);
```

Output:

```text
Current number: 10
Current sum: 10

Current number: 20
Current sum: 30

Current number: 30
Current sum: 60

Final sum: 60
```

This helps you understand **what your program is actually doing**.

# 🧩 9. Mini Project – Student Result System

Let's combine:

```text
Arrays
   +
Loops
   +
Conditions
   +
Functions
   +
Objects
```

### 💻 Code

```javascript
function calculateTotal(marks) {
    let total = 0;

    for (let mark of marks) {
        total += mark;
    }

    return total;
}

function calculateAverage(marks) {
    let total = calculateTotal(marks);

    return total / marks.length;
}

function getGrade(average) {

    if (average >= 90) {
        return "A+";
    } else if (average >= 80) {
        return "A";
    } else if (average >= 70) {
        return "B";
    } else if (average >= 60) {
        return "C";
    } else {
        return "F";
    }
}

let student = {
    name: "Ajith",
    marks: [85, 90, 78, 92, 88]
};

let total = calculateTotal(student.marks);
let average = calculateAverage(student.marks);
let grade = getGrade(average);

console.log("Student:", student.name);
console.log("Total:", total);
console.log("Average:", average);
console.log("Grade:", grade);
```

### 🖥️ Output

```text
Student: Ajith
Total: 433
Average: 86.6
Grade: A
```

### 🧠 What did we use?

```text
📦 Object
   ↓
student

📚 Array
   ↓
marks

🔄 Loop
   ↓
Calculate total

⚙️ Functions
   ↓
Organize logic

🔀 Conditions
   ↓
Determine grade
```
