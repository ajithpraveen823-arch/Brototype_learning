## 🟨 1. What is JavaScript?

**JavaScript (JS)** is a programming language mainly used to make websites and applications interactive and dynamic.

### 💡 What can JavaScript do?

- 🖱️ Respond to button clicks
- 📝 Validate forms
- 🎨 Modify HTML and CSS
- ✨ Create animations
- 🌐 Fetch data from APIs
- 🖥️ Build web applications
- ⚙️ Build backend applications using Node.js
